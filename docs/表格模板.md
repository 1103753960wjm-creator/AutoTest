# TestHub 统一列表表格模板规范 (Unified Table Template Spec)

本规范定义了 `TestHub` 智能测试管理平台（以及后续新项目）中所有标准列表页面的统一开发规范。该规范旨在收口 ad-hoc 散写、消除视觉不一致、提供稳定分页与增强的高频操作支持。

---

## 1. 核心设计与架构分层

标准列表页面开发需严格采用以下四层组件模型：

```
+-------------------------------------------------------------+
|                      PlatformPageHeader                      | (页头区：注入标题、辅助提示、页头主动作按钮)
+-------------------------------------------------------------+
|                          ListShell                          | (页面主外壳：负责统一列表容器与最大宽度约束)
|  +-------------------------------------------------------+  |
|  |                     .filters (Row)                    |  | (搜索筛选栏：符合 UI 一致化规范的检索容器)
|  +-------------------------------------------------------+  |
|  |                     ui-states (Div)                   |  | (加载中/异常/无权限/无数据/搜索空态组件)
|  +-------------------------------------------------------+  |
|  |                   UnifiedListTable                    |  | (统一表格组件：接管列配置、勾选、分页与双击)
|  +-------------------------------------------------------+  |
+-------------------------------------------------------------+
```

---

## 2. 前端样式 UI 一致性红线

1. **搜索筛选栏位置与间距**：
   - 统一在 `ListShell` 的 `#filters` 插槽中渲染独立的 `.filters` 容器。
   - 禁止在 `ListShell` 的 `#filters` 插槽里再嵌套一层卡片（避免形成双重卡片及双边框阴影）。
   - 过滤列需使用 `el-row :gutter="16"` 或 `20` 布局，保证不同分辨率下的网格节奏一致。
   - `el-input`、`el-select`、`el-date-editor` 必须撑满所在列宽；`ListShell` 已提供兜底，页面模板仍应显式遵守该口径。
2. **表格与分页样式**：
   - 必须复用公共 `UnifiedListTable` 组件，表头背景统一为浅灰色 (`#f5f7fa`)，必须带有完整网格边框 (`border`)。
   - 最左侧必须固定为 **序号列** 和 **多选框列**。
   - 最右侧必须固定为 **操作列**，操作按钮统一采用 Element Plus 链接型按钮 (`el-link type="primary" link`)。
3. **页面状态联动机制 (`pageState`)**：
   - 必须依据请求的流转，联动渲染以下五种统一状态：
     *   `StateLoading`：加载列表的首屏或重置时（非轮询）。
     *   `StateForbidden`：接口返回 `403` 时展示。
     *   `StateError`：接口调用异常时，展示重试按钮与具体错误详情。
     *   `StateEmpty`：系统在无活动过滤时（即无搜索词且无过滤项）返回数据总数为 `0` 时展示。
     *   `StateSearchEmpty`：系统在有活动过滤条件下返回数据总数为 `0` 时展示，提供“一键清空筛选”按钮。

## 3. 标准代码模板 (Vue 3 Script Setup)

此模板提取自测试用例列表与 AI 执行记录页的最佳实践，可直接作为新页面的脚手架：

```vue
<template>
  <ListShell>
    <!-- 1. 搜索筛选区 (排版与 ProjectManagement 严格对齐) -->
    <template #filters>
      <div class="filters">
        <el-row :gutter="16">
          <!-- 模糊搜索 -->
          <el-col :span="8">
            <el-input
              v-model="searchText"
              placeholder="请输入用例名称进行搜索..."
              clearable
              style="width: 100%"
              @input="handleSearch"
              @clear="handleSearch"
            >
              <template #prefix>
                <el-icon><Search /></el-icon>
              </template>
            </el-input>
          </el-col>
          <!-- 条件过滤 -->
          <el-col :span="8">
            <el-select
              v-model="projectFilter"
              placeholder="关联项目"
              clearable
              style="width: 100%"
              @change="handleFilter"
            >
              <el-option
                v-for="project in projects"
                :key="project.id"
                :label="project.name"
                :value="project.id"
              />
            </el-select>
          </el-col>
        </el-row>
      </div>
    </template>

    <!-- 2. 统一页面状态机联动 -->
    <StateLoading v-if="pageState === UI_PAGE_STATE.LOADING" compact />
    <StateForbidden
      v-else-if="pageState === UI_PAGE_STATE.FORBIDDEN"
      compact
      primary-action-text="返回首页"
      @primary-action="router.push('/home')"
    />
    <StateError
      v-else-if="pageState === UI_PAGE_STATE.REQUEST_ERROR"
      compact
      :description="requestErrorMessage"
      @primary-action="fetchList"
    />
    <StateSearchEmpty
      v-else-if="pageState === UI_PAGE_STATE.SEARCH_EMPTY"
      compact
      primary-action-text="清空筛选条件"
      @primary-action="resetFilters"
    />
    <StateEmpty
      v-else-if="pageState === UI_PAGE_STATE.EMPTY"
      compact
      primary-action-text="新建资产"
      @primary-action="handleCreate"
    />

    <!-- 3. 标准表格与分页展示 -->
    <template v-else>
      <div class="table-container">
        <UnifiedListTable
          v-model:currentPage="currentPage"
          v-model:pageSize="pageSize"
          :page-sizes="[15, 25, 35, 50, 100]"
          :total="total"
          :data="listData"
          :loading="tableLoading"
          row-key="id"
          selection-mode="multi"
          :actions="{
            view: true,
            edit: true,
            delete: true
          }"
          :delete-name="(row) => row?.title || ''"
          @selection-change="handleSelectionChange"
          @view="handleView"
          @edit="handleEdit"
          @delete="handleDeleteConfirmed"
          @row-dblclick="handleEdit"
          @page-change="fetchList"
        >
          <!-- 业务列配置 -->
          <el-table-column prop="title" label="用例名称" min-width="250">
            <template #default="{ row }">
              <el-link @click="handleView(row)" type="primary">
                {{ row.title }}
              </el-link>
            </template>
          </el-table-column>
          <el-table-column prop="project.name" label="关联项目" width="150" />
          <el-table-column prop="created_at" label="创建时间" width="180">
            <template #default="{ row }">
              {{ formatDate(row.created_at) }}
            </template>
          </el-table-column>
        </UnifiedListTable>
      </div>
    </template>
  </ListShell>
</template>

<script setup>
import { ref, onMounted, computed } from 'vue'
import { useRouter, useRoute } from 'vue-router'
import { ElMessage, ElMessageBox } from 'element-plus'
import { Plus, Search, Download, Delete } from '@element-plus/icons-vue'
import api from '@/utils/api'
import dayjs from 'dayjs'
import { exportRowsToExcel } from '@/utils/excelExport'
import { usePlatformPageHeader } from '@/layout/usePlatformPageHeader'
import { UnifiedListTable } from '@/components/platform-shared'
import { StateEmpty, StateError, StateForbidden, StateLoading, StateSearchEmpty, UI_PAGE_STATE } from '@/components/ui-states'

const route = useRoute()
const router = useRouter()

// 状态定义
const tableLoading = ref(false)
const listData = ref([])
const total = ref(0)
const currentPage = ref(1)
const pageSize = ref(15)

// 筛选字段
const searchText = ref('')
const projectFilter = ref(null)
const projects = ref([])

// 页面加载阶段
const hasLoaded = ref(false)
const requestState = ref(`${UI_PAGE_STATE.READY}`)
const requestErrorMessage = ref('')
const selectedRows = ref([])
const isActionRunning = ref(false)

// 校验当前是否有活动筛选
const hasActiveFilter = computed(() => (
  Boolean(searchText.value) ||
  projectFilter.value !== null
))

// 统一状态流转计算属性
const pageState = computed(() => {
  let state = String(UI_PAGE_STATE.READY)
  if (tableLoading.value && !hasLoaded.value) {
    state = UI_PAGE_STATE.LOADING
  } else if (requestState.value === UI_PAGE_STATE.FORBIDDEN) {
    state = UI_PAGE_STATE.FORBIDDEN
  } else if (requestState.value === UI_PAGE_STATE.REQUEST_ERROR) {
    state = UI_PAGE_STATE.REQUEST_ERROR
  } else if (listData.value.length === 0) {
    state = hasActiveFilter.value ? UI_PAGE_STATE.SEARCH_EMPTY : UI_PAGE_STATE.EMPTY
  }
  return state
})

// 绑定顶部页头操作与信息
usePlatformPageHeader(() => ({
  helperText: '测试用例标准列表管理范式说明。',
  metaItems: [
    { label: '总记录数', value: `${total.value}` },
    { label: '已选记录', value: `${selectedRows.value.length} 项` }
  ],
  actions: [
    // 动态批量删除按钮
    selectedRows.value.length > 0
      ? {
          key: 'batch-delete',
          label: `批量删除 (${selectedRows.value.length})`,
          type: 'danger',
          icon: Delete,
          onClick: handleBatchDelete
        }
      : null,
    // 导出 Excel
    {
      key: 'export-excel',
      label: '导出 Excel',
      plain: true,
      icon: Download,
      onClick: handleExportExcel
    },
    // 新建
    {
      key: 'create-btn',
      label: '新建用例',
      type: 'primary',
      icon: Plus,
      onClick: handleCreate
    }
  ].filter(Boolean)
}))

// 获取列表数据
const fetchList = async () => {
  tableLoading.value = true
  requestState.value = UI_PAGE_STATE.READY
  requestErrorMessage.value = ''
  let shouldRefetch = false
  try {
    const params = {
      page: currentPage.value,
      page_size: pageSize.value,
      search: searchText.value,
      project: projectFilter.value
    }
    const response = await api.get('/testcases/', { params })
    listData.value = response.data.results || []
    total.value = response.data.count || 0
    
    // 【关键防御性设计】页码越界回退
    const maxPage = Math.max(1, Math.ceil(total.value / pageSize.value || 1))
    if (currentPage.value > maxPage) {
      currentPage.value = maxPage
      shouldRefetch = true
      return
    }
    hasLoaded.value = true
  } catch (error) {
    ElMessage.error('获取列表数据失败')
    requestState.value = error.response?.status === 403 ? UI_PAGE_STATE.FORBIDDEN : UI_PAGE_STATE.REQUEST_ERROR
    requestErrorMessage.value = error.response?.data?.detail || error.message || ''
    hasLoaded.value = true
  } finally {
    if (!shouldRefetch) {
      tableLoading.value = false
    }
  }
  if (shouldRefetch) {
    await fetchList()
  }
}

// 检索触发
const handleSearch = () => {
  currentPage.value = 1
  fetchList()
}

const handleFilter = () => {
  currentPage.value = 1
  fetchList()
}

// 重置检索
const resetFilters = () => {
  searchText.value = ''
  projectFilter.value = null
  currentPage.value = 1
  fetchList()
}

// 多选状态变化
const handleSelectionChange = (selection) => {
  selectedRows.value = selection
}

// 跳转逻辑
const handleCreate = () => {
  router.push('/testcases/create')
}

const handleView = (row) => {
  router.push(`/testcases/${row.id}`)
}

const handleEdit = (row) => {
  router.push(`/testcases/${row.id}/edit`)
}

// 单条删除
const handleDeleteConfirmed = async (row) => {
  try {
    await api.delete(`/testcases/${row.id}/`)
    ElMessage.success('删除成功')
    await fetchList()
  } catch (error) {
    ElMessage.error(error.response?.data?.detail || '删除失败')
  }
}

// 批量删除
const handleBatchDelete = async () => {
  if (selectedRows.value.length === 0) return
  try {
    await ElMessageBox.confirm(
      `确定要删除选中的 ${selectedRows.value.length} 个测试用例吗？此操作不可逆。`,
      '警告',
      {
        confirmButtonText: '确定',
        cancelButtonText: '取消',
        type: 'warning'
      }
    )
    isActionRunning.value = true
    const ids = selectedRows.value.map(row => row.id)
    await api.post('/testcases/batch-delete/', { ids })
    ElMessage.success('批量删除成功')
    selectedRows.value = []
    await fetchList()
  } catch (error) {
    if (error !== 'cancel') {
      ElMessage.error(error.message || '批量删除失败')
    }
  } finally {
    isActionRunning.value = false
  }
}

// 智能 Excel 导出
const handleExportExcel = async () => {
  try {
    tableLoading.value = true
    let exportData = []

    if (selectedRows.value.length > 0) {
      // 1. 如果勾选了数据，仅导出勾选的部分
      exportData = selectedRows.value
    } else {
      // 2. 如果未勾选数据，循环递归拉取当前过滤条件下的全量列表
      const exportPageSize = 100 // 调大分页参数，加快读取速度
      let page = 1
      let hasMore = true
      
      while (hasMore) {
        const response = await api.get('/testcases/', {
          params: {
            page,
            page_size: exportPageSize,
            search: searchText.value,
            project: projectFilter.value
          }
        })
        const results = response.data.results || []
        exportData.push(...results)
        
        if (results.length < exportPageSize) {
          hasMore = false
        } else {
          page++
        }
      }
    }

    if (exportData.length === 0) {
      ElMessage.warning('没有可导出的数据')
      return
    }

    // 组装 Excel 工作表
    const worksheetData = [
      ['编号', '用例名称', '关联项目', '创建人', '创建时间']
    ]
    exportData.forEach((row, index) => {
      worksheetData.push([
        `TC${String(index + 1).padStart(3, '0')}`,
        row.title || '',
        row.project?.name || '',
        row.author?.username || '',
        dayjs(row.created_at).format('YYYY-MM-DD HH:mm')
      ])
    })

    await exportRowsToExcel({
      rows: worksheetData,
      columns: [
        { width: 10 }, // 编号
        { width: 40 }, // 用例名称
        { width: 20 }, // 关联项目
        { width: 15 }, // 创建人
        { width: 20 }  // 创建时间
      ],
      sheetName: '测试用例',
      fileName: `TestCase_Export_${dayjs().format('YYYYMMDD')}.xlsx`,
      headerStyle: {
        font: { bold: true },
        alignment: { horizontal: 'center', vertical: 'middle', wrapText: true }
      },
      bodyStyle: {
        alignment: { vertical: 'top', wrapText: true }
      }
    })
    ElMessage.success('数据导出成功')
  } catch (error) {
    ElMessage.error(`导出失败: ${error.message}`)
  } finally {
    tableLoading.value = false
  }
}

// 格式化函数
const formatDate = (dateString) => {
  return dayjs(dateString).format('YYYY-MM-DD HH:mm')
}

onMounted(() => {
  fetchList()
})
</script>
```

## 4. 高频防错与健壮性设计规范

1. **页码越界回退防空屏**：
   在单条或批量删除用例后，若删除动作导致当前页的项数归零，而当前页码并非第一页，会导致页面变为空屏。模板中的越界回退逻辑：
   ```javascript
   const maxPage = Math.max(1, Math.ceil(total.value / pageSize.value || 1))
   if (currentPage.value > maxPage) {
     currentPage.value = maxPage
     shouldRefetch = true
     return
   }
   ```
   该机制可在计算出最新最大页码后，自动回退并二次拉取数据，防止界面挂死。

2. **带检索与勾选判断的静默轮询**：
   如果列表页面需要周期性轮询更新（例如任务执行状态等），必须在轮询中处理以下两个细节：
   *   **携带搜索状态**：轮询请求参数中必须挂载当前筛选器中的 `search` 关键字等条件，以避免轮询刷新强制重置用户的搜索框。
   *   **操作防打断**：仅在 `selectedRows.value.length === 0`（即用户没有任何行勾选动作）时才可以把返回的数据写回 state，防止重新赋值时冲掉用户的勾选态导致批量删除失败。

# 任务文档模板说明

## 1. 文件职责

本目录用于存放 `Spec/SDD`、`TDD`、`VDD` 的标准模板，保证每轮任务的需求确认、测试设计和交付验证都能被软件测试工程师用大白话看懂。

## 2. 使用规则

- 非“小修小改”任务必须按模板生成任务文档。
- 小修小改可以在对话中给出最小版 `Spec/TDD/VDD`，但字段含义仍要对齐模板。
- 任务文档默认落盘到 `docs/tasks/YYYY-MM-DD-任务名/`。
- 同一任务建议至少包含：
  - `spec-sdd.md`
  - `tdd.md`
  - `vdd.md`
- 文档必须使用 UTF-8 编码。
- 文档必须使用中文大白话和细颗粒度表达，不得只给技术结论。

## 3. 模板文件

- `spec-sdd-template.md`：需求确认、范围、方案、风险和验收口径
- `tdd-template.md`：测试目标、测试场景、验证数据、失败场景和通过标准
- `vdd-template.md`：执行结果、验证证据、是否通过、未验证项和残余风险

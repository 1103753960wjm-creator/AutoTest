# 任务文档目录

## 1. 文件职责

本目录用于保存每轮非“小修小改”任务的 `Spec/SDD`、`TDD`、`VDD` 文档。

## 2. 命名规则

每轮任务使用独立目录：

```text
docs/tasks/YYYY-MM-DD-任务名/
```

目录内建议文件：

```text
spec-sdd.md
tdd.md
vdd.md
```

## 3. 写作规则

- 必须使用 UTF-8 编码。
- 必须使用中文大白话、细颗粒度表达。
- 必须让不写代码的软件测试工程师也能判断范围、风险、验收、失败和回退。
- 文档模板统一参考 `docs/task-templates/`。

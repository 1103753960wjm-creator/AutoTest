# Spec/SDD：剩余 P0.1 全量关闭

## 背景

- 当前问题：`full-stack-optimization-implementation-plan.md` 中各部分 P0.1 尚未全部关闭。已完成的是“P0.1 第一批”，主要覆盖前端设计 token、前端请求入口收口、后端权限第一批补口。
- 触发原因：用户要求进入下一步，需要继续关闭剩余 P0.1，而剩余范围涉及后端权限、接口认证一致性、模拟实现清理和注释清理，属于高风险链路，不能直接改代码。

## 目标

- 本次要解决：
  - 关闭接口治理 P0.1：接口权限和认证一致性。
  - 关闭后端代码 P0.1：模拟实现和临时代码清理。
  - 关闭注释文档 P0.1：删除误导性注释。
  - 补齐上一批 P0.1 未验证项：真实浏览器主流程、真实 App 报告文件访问、真实无权限对象 403、浏览器 EventSource 凭据行为。

## 非目标

- 本次明确不做：
  - 不进入 P0.2、P0.3、P1 或 P2。
  - 不新增数据库模型，不做迁移。
  - 不重写 AI 生成主链、执行器主链、报告生成主链。
  - 不引入新依赖。
  - 不为通过验证而放宽权限、跳过认证或屏蔽错误。
  - 不清理所有历史 TODO，只处理会误导 P0.1 上线验收的注释和临时代码。

## 范围

- 受影响模块：
  - 后端接口权限：`apps/**/views*.py`、`backend/urls.py`、必要的权限工具或测试辅助。
  - 后端模拟 / 临时代码：重点检查 `apps/ui_automation/views.py`、`apps/api_testing/views.py`、执行器和报告相关代码。
  - 注释文档：前后端源码中的 `模拟`、`临时`、`兼容`、`TODO`、`FIXME`，以及上线限制说明。
  - 验证文档：`docs/tasks/2026-07-04-p0-1-remaining-closure/`、项目记忆和更新日志。

## 已知事实

- 已完成：
  - 前端 UI P0.1 设计令牌最小集。
  - 前端代码 P0.1 请求入口收口。
  - 后端权限第一批补口。
- 未完成：
  - 接口权限和认证一致性仍需全量扫描和补测试口径。
  - 模拟实现和临时代码清理未进入上一批。
  - 删除误导性注释未进入上一批。
- 已知未验证项：
  - App 报告真实文件 200。
  - 真实无权限对象 403。
  - 浏览器 EventSource 凭据行为。
  - 真实浏览器主流程。

## 方案设计

- 核心方案：
  - 先做静态扫描，列出所有权限、公开接口、模拟实现和误导性注释候选清单。
  - 对公开接口建立或更新白名单，非公开接口默认要求认证。
  - 对对象资源补项目 / 用户对象权限，失败返回 401/403。
  - 对模拟实现分三类处理：能低风险真实闭环的修为真实实现；不能真实闭环但用户可见的隐藏或返回 501；只是注释误导的改注释或移入限制说明。
  - 对注释只处理会误导上线验收的内容，不做全仓文案美化。

## 风险点

- 权限收紧可能影响旧页面正常访问，需要真实登录态验证。
- 模拟实现清理可能暴露未完成能力，需要用 501、隐藏入口或限制说明明确告知。
- 注释清理可能误删仍有价值的历史兼容说明，需要逐条判断。
- 后端环境可能缺少真实样本数据，导致部分验证只能停留在静态或有限请求级。

## 待确认项

- 已确认：允许本轮对用户可见但未真实闭环的入口做隐藏或改为 501。
- 已确认：可以由 AI 制造本地验证样本数据。
- 待执行约束：样本数据只能写入本地开发库，必须使用可识别前缀，例如 `P0_SAMPLE_`，验证后必须说明如何清理。
- 待确认：是否允许新增最小后端测试脚本或临时验证脚本，但不新增运行依赖？

## 验收标准

- [ ] 公开接口白名单完整，且白名单之外敏感接口默认需要认证。
- [ ] 未登录访问敏感接口返回 401 或 403。
- [ ] 无权限访问对象资源返回 403。
- [ ] 用户有权限时仍可访问自己的资源。
- [ ] 用户可见页面不展示伪造执行结果。
- [ ] 模拟 / 临时能力要么真实闭环，要么隐藏 / 501 / 写入上线限制说明。
- [ ] 误导性注释已删除或改成准确限制说明。
- [ ] `npm run build`、后端编译 / 请求级验证、规则检查和静态扫描通过或说明未执行原因。

## 回退方式

- 如果权限收紧影响正常访问：回退对应权限变更文件，并保留白名单和失败证据。
- 如果模拟实现清理影响页面流程：先隐藏入口或恢复原入口，再把该能力列入 P0 后续任务。
- 如果验证数据不足：不扩大实现范围，记录阻塞并等待样本数据。
- 如果样本数据创建失败：停止请求级验证，不伪造验证通过，只保留静态和编译验证结果。

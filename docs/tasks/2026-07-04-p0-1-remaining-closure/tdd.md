# TDD：剩余 P0.1 全量关闭

## 验证目标

- [ ] 证明公开接口白名单之外的敏感接口不能匿名访问。
- [ ] 证明对象资源接口会校验当前用户是否有权限访问该对象。
- [ ] 证明有权限用户访问自己的资源不被误伤。
- [ ] 证明本地样本数据可以支撑“本人资源 200 / 他人资源 403 / 未登录 401”三类验证。
- [ ] 证明用户可见页面不再展示伪造执行结果或明显“假入口”。
- [ ] 证明误导性注释已被删除、改准或转为限制说明。
- [ ] 证明前端构建和规则扫描仍通过。

## 失败场景

- 权限 / 状态不允许：
  - 未登录访问敏感接口仍返回 200。
  - 无权限对象访问仍返回 200 或泄露文件。
  - 有权限对象访问被误判 403。
- 参数边界：
  - 传不存在的对象 id。
  - 传其他用户 / 其他项目对象 id。
  - 传非法报告文件路径或路径穿越。
- 依赖失败 / 超时：
  - 后端未启动。
  - 缺少真实 App 报告样本。
  - 缺少双用户权限样本。
- 并发 / 重复提交：
  - 快速重复访问进度 / 报告接口时不能绕过权限。
  - EventSource 重连不能绕过登录态和对象权限。

## 验证层级

- 本次目标验证等级：V3 行为验证；若具备真实双用户和报告文件样本，争取达到 V4 回归验证。
- 选择原因：剩余 P0.1 涉及权限和用户可见入口，单纯构建验证不能证明安全和体验。

## 最小验证清单

- 静态扫描：
  - 命令：`rg -n "AllowAny|permission_classes\\s*=\\s*\\[\\]|csrf_exempt|login_required" apps backend -g "*.py"`
  - 通过标准：所有命中项要么在公开白名单，要么有认证 / 对象权限理由。
- 公开接口白名单核对：
  - 命令 / 操作：核对 `docs/tasks/2026-07-04-p0-1-remaining-closure/public-api-whitelist.md`。
  - 通过标准：公开接口有理由，敏感接口不在白名单。
- 后端编译：
  - 命令：`python -m py_compile` 覆盖本轮修改的后端文件。
  - 通过标准：无语法错误。
- 请求级权限验证：
  - 操作：未登录访问需求生成、配置状态、任务进度、报告文件等敏感接口。
  - 通过标准：返回 401 或 403。
- 对象权限验证：
  - 操作：用户 A 访问用户 B 或其他项目对象资源。
  - 通过标准：返回 403；用户 A 访问自己资源返回 200。
- 样本数据准备：
  - 操作：用 Django ORM 或 DRF 测试客户端在本地开发库创建 `P0_SAMPLE_` 前缀用户、项目、任务、执行记录和报告文件样本。
  - 通过标准：样本能覆盖本人资源、他人资源、未登录访问、报告文件存在和报告文件路径非法五类情况；验证结束后给出清理方式。
- 模拟实现扫描：
  - 命令：`rg -n "模拟|临时|TODO|FIXME|NotImplemented|未实现|开发中|mock" apps frontend/src docs -g "*.py" -g "*.js" -g "*.vue" -g "*.md"`
  - 通过标准：P0 用户可见链路中无误导性假成功 / 假入口。
- 前端验证：
  - 命令：`cd frontend && cmd /c npm run build`
  - 通过标准：构建通过，只允许既有已说明警告。
- 规则检查：
  - 命令：`powershell -ExecutionPolicy Bypass -File scripts\\rule_check.ps1`
  - 通过标准：无 P0 红线命中。
- 浏览器回归：
  - 操作：登录后进入需求分析、接口自动化、App 报告入口、关键列表 / 详情 / 编辑页。
  - 通过标准：页面不整页刷新，不出现权限误伤，不出现假成功。

## 失败判定

- 任一敏感接口匿名返回 200，视为失败。
- 任一无权限对象返回 200 或泄露文件，视为失败。
- 用户可见假入口仍显示“开发中”但无真实闭环，视为失败。
- 为通过验证而放宽权限、隐藏异常或跳过检查，视为失败。

## 本轮暂停条件

- 需要新增数据模型或迁移。
- 需要重写 AI、执行器或报告主链。
- 缺少真实样本导致无法判断权限正确性。
- 本地数据库不可用，或样本数据创建会污染非开发环境。
- 修改范围超出 P0.1 剩余清单。

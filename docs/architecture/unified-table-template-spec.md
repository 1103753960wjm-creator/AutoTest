# 统一表格模板规范

## 1. 文件职责

本文是统一表格模板规范的稳定英文文件名入口，用于承接历史引用中的 `unified-table-template-spec.md`。

当前详细规范以同目录下的 [表格模板.md](./表格模板.md) 为准。

## 2. 使用口径

- 新增或改造列表页时，优先使用统一页面壳和统一表格组件。
- 筛选区、操作按钮、表格、分页器的布局顺序和间距必须与平台标准页面保持一致。
- `ListShell #filters` 是列表筛选区正式插槽，筛选控件必须撑满所在列宽。
- 不得为单个页面重新设计一套 ad-hoc 搜索区或表格布局。
